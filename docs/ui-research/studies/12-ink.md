# SP-01：喷射战士 2 设置界面 → 墨彩饭局

## 选取

[Interface In Game 的 Splatoon 2 Options](https://interfaceingame.com/screenshots/splatoon-2-options/) 实机界面档案，[SP-01](../references/ink/SP-01-options.jpg)。原计划选取任天堂 Splatoon 3 教程，但页面获取失败，最终明确采用第二作截图，不混写版本。

## 观察与分析

顶部一排拱顶分页，未选项紫色、当前项橙色；选中页边缘有少量滴墨。左侧模式是粗圆的胶囊选项，当前项粉色，下方黑色。右侧连续深色圆角条承托设置。文字粗而柔软，白字带小幅阴影；背景三维广场高度失焦，前景灰色大面板略带透视和半透明。墨迹形状出现在装饰、标签边缘，主体内容并未任意旋转。

## 实施

名称「喷射战士 · 墨彩饭局」，key `ink`。顶部概览是一条圆角横幅；宽屏将吃/不吃作为左侧纵向胶囊选项，候选是右侧较大的深色面板；手机还原为候选下方并列操作。底部固定导航用拱顶分页与橙色当前项，列表与历史用圆条块；粉色作为次操作，避免与主要操作混淆。

原创 SVG 仅绘制墨迹和点阵，未使用原作角色、标识或游戏图片。正文保持正向，只有装饰戳记轻微倾斜；透明容器下面有可读的深色实底。轻量悬停与按下反馈遵循减少动态效果设置。未从静态参考推导原作动画曲线。

## 验证

28 个 Chromium 场景和 4 项主题偏好测试通过。审阅 [桌面](../previews/ink/desktop.png)、[手机](../previews/ink/mobile.png) 与 [菜单](../previews/ink/menu.png)，[检查报告](../previews/ink/validation.json)。候选在手机全宽，正常状态两项按钮首屏可见；长文本、通知、页脚和固定导航检查通过。未做 Android 真机验收。
