# MR-01/02：Marathon Cradle 与物品转换 → 食欲协议

## 选取

Bungie 官方 [Welcome to Season 2](https://www.bungie.net/7/en/News/article/welcome_season_2)，2026-05-27，第二赛季介绍中的 [Cradle](../references/marathon/MR-01-cradle.jpg) 与 [Convert Matter](../references/marathon/MR-02-convert.jpg)。采用新版 Marathon，而非 1994 年作品；这些是特定时期的官方画面，不据此声称当前客户端布局完全相同。

## 观察与分析

近黑背景、深灰模块与明亮的荧光绿主操作。主标题使用衬线字，说明和数据使用等宽字，小标签则有宽而粗的无衬线字。Cradle 左侧横向能力条对齐成行，右侧较大说明卡有图像、标题及数据；物品转换页右边是密集的不同尺寸物品网格，每格左上角有小型亮色标签。青色、紫色、黄绿在黑底上形成分组，只有少量圆角和胶囊形，绝非统一的斜切多边形。

连接线、点阵、裁切十字和宽重文字是次层纹理。原图有微弱屏幕质感，但无法从静态图得到刷新或闪烁规律。文字本身未明显倾斜，不能以全局 skew 代替这套排版。

## 实施

名称「马拉松 · 食欲协议」，key `marathon`。左侧衬线标题与原创餐次连接图，右侧深灰候选模块，主操作荧光绿；真实统计用青/紫色底边区分。菜单是双列格状卡片，窄屏单列；历史采用离散条块，表单与通知保持相同模块语言。首页手机压缩概览，保留全宽候选。

原创 SVG 连接餐碗、记录与添加符号，全部只是装饰，没有虚假的经验、货币、生命值和填充率。沿用已有文字与吃/不吃流程，没有把日常记录改造成游戏经济系统。圆角较小，触控面积与长名字换行保留；动态效果为本应用自定，支持减少动态效果。

## 验证

28 个 Chromium 布局场景与 4 项主题偏好测试通过。审阅 [桌面](../previews/marathon/desktop.png)、[手机](../previews/marathon/mobile.png) 和 [菜单](../previews/marathon/menu.png)，[检查报告](../previews/marathon/validation.json)。覆盖四页面、360–1060px、长文本、空/忙碌状态与悬浮通知。手机正常候选的两项操作完整可见。SSR 不执行真实点击事件，也不替代 Android 真机验收。
