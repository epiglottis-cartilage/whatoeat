# NA-01：NieR:Automata → 日常档案

## 选取

来源为开发商 PlatinumGames 的 [UI 设计开发日志](https://www.platinumgames.co.jp/dev-nier-automata/article/183)，2017-08-25，作者木嶋久善。选取武器详情屏而非宣传封面：它提供可直接迁移的信息分栏、标题条和装饰层。原图 [NA-01](../references/automata/NA-01-weapon.png)，1600 × 900；元数据见 `sources.json`。

## 可观察特征

- 米色底上覆盖细网格；深灰文字，明暗差异承担大部分层级。
- 左上大写标题，细横线限定副标题带；主体两块宽度不同的浅色信息区。
- 信息区无圆角、没有夸张投影；右侧小标题使用深色反白条。
- 上下边缘线条附小方块与点阵；背景有大尺度曲线与斜线，位于正文之下。
- 正文保持平直；截图外围存在暗角。不能从这一张图量化镜头运动或转场时长。

开发日志说明其设计结合网格显示器质感与乐谱式符号，并讨论了米色低对比下的可读性。本文将静态证据与本应用的取舍分开，不复现未实测的动效参数。

## 实施决策

显示名「尼尔 · 日常档案」，key `automata`。当前日期、可用菜单和已记餐次组成顶部窄信息带；桌面候选详情与纵向操作栏并列；手机改成垂直档案与横向吃/不吃。菜单、历史按细线档案条组织，复制页采用分节表单。主题图形由 CSS 自行构造；不使用角色、武器图或原作 Logo。

为保证阅读，正文使用比原截图更深的前景；正文与点击区域不做透视扭曲。日期不是关卡编号，餐次数也不是等级。网格和点阵不接收输入；短暂淡入为本应用自定，遵守系统减少动态效果。

## 验证

28 个 Chromium 场景通过：四页面 × 360/390/760/1060 px，候选状态、长列表、通知、控件边界、固定导航和页脚、减少动态效果、可解析的纯色控件对比度。审阅 [桌面截图](../previews/automata/desktop.png) 与 [手机截图](../previews/automata/mobile.png)，[完整静态报告](../previews/automata/validation.json)。39 项 Rust 测试通过，包含全部主题 key 的保存/重开读取。

本次也将主题 CSS 改为仅向 DOM 注入当前选中主题，原有资源仍全部离线内置。共享界面样式与原五套配色保持原入口。SSR 样例不接触用户数据库；安卓真机交互与显示效果未在本轮验证。
