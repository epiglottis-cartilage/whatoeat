# BF-01：战地 1 主菜单 → 休整时刻

## 选取

[Nick Schaden 的历史 UI 评论](https://www.nickschaden.com/2016/11/21/battlefield-1-needs-ui-help/)，2016-11-21，文中实际主菜单 [BF-01](../references/frontline/BF-01-menu.jpg)。图中是 PlayStation 按键提示，具体构建未知。它不是第三方重设计稿；本文仅观察截图，不转述评论文章的结论。

## 观察与分析

背景为失焦的灰蓝战场，前景标题细而宽松。顶端水平分类有细下划线，中间一排大小不等的矩形图文卡片；主选项底部是一大块白色，标题及操作为黑字。其余卡片由深色图像向底部渐暗承托白字。少量橙金色出现在等级和景物中，不能把整个界面概括成卡其军绿色。内容水平对齐，没有整体倾斜；透视属于景物，而非文字。

## 实施

名称「战地 1 · 休整时刻」，key `frontline`。桌面把问候横置在上方，白底候选作为主卡片，右侧日期和真实统计是较窄的深色卡片。手机将概览压缩成问候和统计条，保留全宽候选。菜单与表单采用矩形薄边框，导航使用细下划线选中态；不增设游戏里的新闻、商城或重复快捷入口。

原创 SVG 使用远山、虚化建筑与少量暖光，构成有景深的日常休整背景，不拷贝战争截图、人物或品牌标志。正文仍有实色/深色承托；选中白色卡片用深色文字。动画仅使用本应用自定的轻量入场和悬停，遵循减少动态效果设置。

## 验证

28 个 Chromium 布局场景、4 项主题偏好测试通过。审阅 [桌面](../previews/frontline/desktop.png) 和 [手机](../previews/frontline/mobile.png)，[检查报告](../previews/frontline/validation.json)。手机首屏可看到两项决策及完整说明；四页面长文本、空状态、通知和固定导航纳入检查。SSR 不执行 Dioxus 事件，也不是 Android 真机验收。
