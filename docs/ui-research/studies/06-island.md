# AC-01：Animal Crossing → 小岛食记

## 选取与证据

任天堂 [Play Nintendo 岛屿生活提示](https://play.nintendo.com/news-tips/tips-tricks/animal-crossing-new-horizons-discover-tips/) 中的 Nook Miles 图：[AC-01](../references/island/AC-01-nook-miles.jpg)，1200 × 600。它是两张游戏截图的官方宣传拼版：外部绿色纹样、黄框是图片编排的一部分，不能直接当作游戏内窗口样式。主要分析内部卡片列表与卡片详情。

## 观察

列表由浅色卡片组成，白色边框分隔相邻色块；详情区域保留卡片形状，标题上方集中，正文下方是圆形印章位置。青绿、奶油黄、浅橙承担分类，而正文保持较深颜色。卡片略有手账式偏移，外围设备区域圆润。整体没有复杂透视或锋利描边，层次来自边框、留白和柔软的色块。单帧不提供翻页弹性、选中频率或按钮回弹时长的证据。

## 实施

名称「动森 · 小岛食记」，key `island`。原创小岛与野餐插图，不使用游戏角色、叶片商标或原图。概览是圆顶便签，候选是带浅色标题条的食物卡片；日期与真实统计使用小标签。桌面菜单使用双列卡片，手机变成单列；桌面历史将补记表单与记录分列，手机仍按先表单后历史阅读。导航图标成为圆角小应用按钮，页脚和通知延续原本行为。

印章只表现「已记入这一餐」的状态，不伪造里程、奖励或连胜。深绿正文比参考图更重，以保证小屏文字对比。短按压反馈为本应用自定；减少动态效果时停用。

## 验证

28 个 Chromium 场景通过，4 项偏好持久化测试通过。[桌面](../previews/island/desktop.png)、[手机](../previews/island/mobile.png)、[菜单卡片](../previews/island/menu.png) 已审阅；[布局报告](../previews/island/validation.json)。手机概览在截图审阅后压缩，日期与统计共用底部一行，减少对候选操作区域的挤占。检查覆盖固定导航、末尾页脚、四页面与状态；未做真机运行验收。
