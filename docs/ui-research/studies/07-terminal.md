# FO-01：Fallout Pip-Boy → 补给终端

## 选取

Bethesda 官方 [Fallout 4 Pip-Boy App 公告](https://bethesda.net/en/article/3FcnlLg6GcYEIGQQoWWU4S/fallout-4-pip-boy-app-now-available)，2015-11-05，内嵌的属性页 [FO-01](../references/terminal/FO-01-pipboy.png)。这是伴随应用的平面界面，不把它误记为游戏内腕载设备的拍摄图。具体客户端版本未知。

## 观察与分析

黑底与荧光绿单色；顶部主分页由直线及阶梯式边框连接，下方存在较小的子分类。左侧属性列表对齐，选中项整行反白，右边用一幅单色人物图和说明形成第二列。底部多块状态条以细线分区。扫描线质感可见，但没有从截图量化刷新率、闪烁或屏幕曲率。

识别度来自「分页、反白列表、单色图形与状态栏」的组合。只把某个已有主题染绿不足以对应这张参考。

## 实施

名称「辐射 · 补给终端」，key `terminal`。桌面候选放左侧，右侧是原创补给盒与餐碗线框图、日期和真实菜单/餐次统计。手机将主要决策放在上方，概览移到后面。列表采用间隔底色和细线，选中导航使用括号感边框。外壳增加窄边框和暗色内屏，输入框与选择器使用相同单色语言。

不使用 Vault Boy 或品牌标志；不把记录数叫等级，不捏造生命值或辐射值。轻微辉光仅用于大标题与线框图，正文保持锐利；扫描线位于内容下方且静止。错误保留琥珀色与文字说明，不依赖单一颜色识别。减少动态效果时仍可完整操作。

## 验证

28 个 Chromium 场景、4 项主题偏好测试通过。审阅 [桌面](../previews/terminal/desktop.png) 和 [手机](../previews/terminal/mobile.png)，[检查报告](../previews/terminal/validation.json)。发现并修正手机 flex 子项收缩导致的右侧空余，将「移动候选占满可用宽度」加入持续检查。所有截图为样例数据；真机验收未执行。
