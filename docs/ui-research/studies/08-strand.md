# DS-01：死亡搁浅货物管理 → 一餐之遥

## 选取

小岛工作室官方 [Director’s Cut 入门指南](https://www.kojimaproductions.jp/ja/death-stranding-directors-cut-beginners-guide)，2022-03-31，货物自动整理 [DS-01](../references/strand/DS-01-cargo.jpg)。图片标注 Captured from PS5；指南面向 PC 不意味着这幅图是 PC 捕获。教程添加的洋红色标框不属于界面配色。

## 观察与分析

界面以左侧货物清单、中央人物及货箱、右侧物品说明形成三栏。深蓝灰半透明背景、细白分隔线、窄体字、小型大写标签、蓝色选中行和细小角标组成信息层级。中央货箱使用偏黄绑带，是少量暖色。文字保持水平；空间感来自中央三维物件，而不是把整个表单倾斜。静态截图不提供转场时长证据。

## 实施

名称「死亡搁浅 · 一餐之遥」，key `strand`。宽屏采用日常清单 / 原创等距餐盒 / 当前候选三栏；中屏两栏；手机压缩为小型概览和全宽候选。保留实际日期、菜单数、餐次数，不添加虚假的重量、配送评级或联网状态。

原创 SVG 餐盒使用金属面与暖黄绑带；背景是抽象地形线。候选蓝色标题带与点状边界，历史和菜单采用薄线清单，按钮保持足够面积。悬停只轻微抬升，沿用减少动态效果支持。研究原图不进入应用资源。

## 验证

28 个 Chromium 场景、4 项主题偏好测试通过；审阅 [桌面](../previews/strand/desktop.png) 与 [手机](../previews/strand/mobile.png)，[检查报告](../previews/strand/validation.json)。覆盖四页面、360–1060px、长文本、加载/空状态及悬浮通知；截图使用样例数据，不代表 Android 真机交互验收。
