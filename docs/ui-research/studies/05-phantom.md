# P5-01：Persona 5 → 开饭预告

## 选取

选择武器菜单的历史画面：[参考原图](../references/persona/P5-01-menu.jpg)，1280 × 720。图源为 Gematsu 的 2015 年预告画面，经 [Jiaxin Wen 的 UI 文章](https://jiaxinwen.wordpress.com/2017/04/27/the-ui-design-of-persona-5/) 引用。登记为第三方承载的截图，不能代表当前 Royal 版本。官方站点可用于确认作品身份，但本站装饰图不作为菜单结构证据。

## 逐图观察

画面左侧大面积黑白人物剪影，右侧倾斜的黑色装备信息区域；白色边框和高亮红条把选择与背景分开。列表正文依然有清楚的横向基线。左下 COMMAND 采用错位字母和黑白描边，背景有星形和半调点阵；顶部武器栏以不规则长条强调层级。红色承担强调而不是给每个细项分别着色。

图上可以观察角度不同的纸片与描边，不能从单帧断言各部分的滑入顺序、持续时间或振动频率。本应用的短入场是独立设计。

## 迁移与实现

名称「P5 · 开饭预告」，key `phantom`。保留红黑白三色、剪贴式标题和非对称分区：左侧是日期与开饭宣言，右侧是当前唯一候选的白纸片；黑底承托白框，吃的按钮使用红色强调。用原创星形、点阵、斜切背景替代角色剪影。菜单与历史采用黑色条目、白色标签；复制页面保持清晰的表单盒子。

倾斜集中在背景、标题与日期纸片；输入、菜名和实际操作区保持可读。移动端把左右关系改成上下，缩小装饰角度、保持固定导航和悬浮通知。不存在自动播放的闪烁或持续背景运动。

## 验证

28 个 Chromium 布局场景通过，包括四页面、四种宽度、推荐状态、长菜名、长历史、悬浮通知、固定导航、页脚及纯色控件对比度。审阅 [桌面](../previews/phantom/desktop.png) 与 [手机](../previews/phantom/mobile.png) 截图；[检查报告](../previews/phantom/validation.json)。4 项偏好测试通过，涵盖新 key 的保存与重新打开。使用显式预览数据，不读写真实饮食记录；未做真机端到端验证。
