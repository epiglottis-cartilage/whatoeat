## 实施约束

- 保留全部已有配色、主题及持久化 key；主题选择仍使用下拉菜单。
- 每套需要独立的空间布局、形状或文字层级，不能只替换颜色。
- 单一候选、吃/不吃、菜单操作、记录与复制合并共享业务代码。
- 导航固定，页脚在内容末尾出现在导航上方，通知不改变布局。
