## 证据如何阅读

- **观察**：能在已存档图像中直接指出的形状、文字、位置、遮挡关系。
- **估计**：由截图估读的相对尺寸、角度、色彩；明确注明误差和场景依赖。
- **推断**：对视觉用途、层次或构造方式的解释，不冒充游戏内部实现。
- **待验证**：没有视频、帧序列或交互操作证据时，不给出确定的时长、缓动、鼠标视差或焦点行为。
- **迁移假设**：未来怎样用于本应用；它是候选设计方向，不是本轮实现承诺。

历史界面和社区截图可以作为具体版本的观察样本，但不能代表游戏的所有版本。官方素材与社区截图会在登记表里分别标识。参考图仅用于本地研究与来源追溯，不放进应用资源或发布包；未取得素材使用许可的事实不会因被存入仓库而改变。
