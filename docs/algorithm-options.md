# 恢复周期模型：公式、可学习参数与收敛

用户已选定模型 B，a、b 两个参数均参与学习；A、C 保留用于对照。B 已在 `src/model.rs` 实现，并接入吃/不吃、撤销与历史回放。`tests/flows.rs` 包含 B 的独立合成反馈测试；此前 Python 实验仅验证模型 A，不能用于声称 B、C 的实测效果。

## 统一定义

对一个用户的一种食物，暂略去用户与食物下标：

- d：距上次实际吃过的天数，d ≥ 0；使用展示时的值。
- x = ln(1 + d)：对数时间特征；d 使用固定单位“天”，严格写法是 ln(1 + d / 1天)。
- y ∈ {0,1}：本次反馈，吃为 1，不吃为 0。
- σ(z) = 1 / (1 + exp(-z))；logit(q) = ln(q / (1-q))。
- p(d)：推荐展示后用户选吃的条件概率。
- T(q) = inf{d ≥ 0 : p(d) ≥ q}：达到目标接受率 q 的最早时间。
- q 初始取 0.7，是产品设定的阈值，不是需要学习的参数。

所有模型预测的都是接受概率，不是实际推荐抽样概率。没有已知食用起点的冷启动样本，不能直接训练时间恢复模型。

## A：只学习周期，一个参数

```text
p(d) = σ(logit(q) + k[x − θ])
θ = ln(1 + T(q))
```

学习 θ；固定 k > 0，建议 k = 2。初始化 θ = ln(8)，对应 T = 7 天。θ 可投影到 [ln(1.25), ln(181)]，将周期限制为 0.25–180 天。

无正则时的精确交叉熵梯度更新：

```text
θ ← Proj(θ + η × k × [p − y])
```

此前设计写成 θ ← θ + η̃(p-y)，是把固定 k 吸收到学习率 η̃ 中。不能在沿用旧学习率数值的同时再乘一次 k，并认为步长没有变化。

优点：数据需求较低，周期直观，固定特征与斜率时损失关于 θ 凸。

限制：所有食物具有相同的恢复形状；无限久之后都趋向 100% 接受。始终拒绝只能推动周期到上界，不能据此推断真实周期。

## B：学习周期和恢复形状，两个参数

```text
p(d) = σ(a + bx), b ≥ b_min > 0
```

学习 a、b。a 控制曲线位置，p(0) = σ(a)；b 控制对数时间上的增长陡峭程度。

```text
T(q) = max(0, exp([logit(q) − a] / b) − 1)
```

用于理论定义的 exp 不做截断；工程输出超过展示或业务上限时标记“超出范围”，不要把截断值误称为真实恢复周期。

模型 A 是模型 B 的特例：b = k，a = logit(q) − kθ。

令 e = p-y。无正则的在线更新为：

```text
a ← a − ηe
b ← max(b_min, b − ηex)
```

两项使用同一更新前快照中的 p、x。正则化后加入 λ(a-a0)、λ(b-b0) 两个梯度项。

固定训练样本时，逻辑回归的交叉熵关于 (a,b) 联合凸，b ≥ b_min 是凸约束。给所有自由参数添加 λ > 0 的 L2 正则可使该有限样本目标强凸，拥有唯一最优解。为保持这个表述，直接优化 b 并投影，不用 b = softplus(β) 后继续声称目标关于 β 凸。

两个参数要有不同时间间隔下的反馈才能被数据区分；若每次都在差不多同一个 d 展示，截距和斜率难以辨别。正则能给出唯一解，不等于数据已证明这两个参数准确。

限制：b > 0 时，长期接受概率仍趋向 1；不适合表达长期也不喜欢。

## C：允许长期也不太想吃，三个参数

```text
r = σ(c)
f(d) = σ(a + bx), b ≥ b_min > 0
p(d) = r × f(d)
```

学习 a、b、c；其中 r 是长期接受概率的上限，lim p(d) = r。r = 0.35 表示在当前建模条件下，即使很久没吃，接受概率也只接近 35%。它不是用户声明的永久喜好，也可能反映模型遗漏的场景因素。

```text
若 q ≤ p(0)：T(q) = 0
若 p(0) < q < r：T(q) = exp([logit(q/r) − a] / b) − 1
若 q ≥ r：不存在有限的 T(q)
```

q = r 时只能在无穷远渐近达到，不应报告有限周期。

令 e = p-y，交叉熵梯度可写成：

```text
g = e × (1-f) / (1-p)
h = e × (1-r) / (1-p)
a ← a − ηg
b ← max(b_min, b − ηgx)
c ← c − ηh
```

数值实现应采用稳定的概率与损失计算。三个更新使用旧参数算出的 f、r、p；正则项另加。

优点：不会强行解释为“只要等足够久就必定想吃”，能区分低上限与恢复慢这两种现象。

限制：短时间、小样本数据通常无法可靠区分“上限低”和“尚未恢复”；需要更宽的时间覆盖、先验或跨食物共享。目标一般不联合凸，梯度训练不能保证全局最优。r 接近 0 或 1 时也容易出现梯度饱和。

## 统一训练目标

对有效且拥有已知 d 的反馈：

```text
L(v) = (1/N) Σ[-y_n ln p_n − (1-y_n) ln(1-p_n)]
       + (λ/2) ||v-v0||²
v ← Proj(v − η_n ∇L_n(v))
```

- v 是各模型的可学习参数。
- v0 为默认先验中心；λ 控制向先验收缩的强度。
- 初始建议使 A、B 的曲线一致：q = 0.7，T0 = 7，k = b0 = 2，a0 = logit(0.7) − 2ln(8)。
- C 需额外指定 r0，并相应设 a0 = logit(q/r0) − b0ln(8)，前提是 r0 > q。r0 是待验证的先验，不是已知事实。

## 参数、超参数与推荐策略分开

| 类别 | 内容 | 来源 |
| --- | --- | --- |
| 可学习参数 | A 的 θ；B 的 a,b；C 的 a,b,c | 每个用户 × 食物的有效反馈 |
| 模型超参数 | 固定斜率 k、约束范围、λ、先验中心 | 初始设计与后续验证 |
| 周期定义 | q，例如 0.7 | 产品定义，不需要与模型一起学习 |
| 优化超参数 | 学习率 η0、衰减速度 | 稳定性与收敛实验 |
| 推荐超参数 | 探索比例 ε、偏向高分的指数 γ | 决策策略，独立于概率模型 |

推荐抽样保持：

```text
π_i = (1-ε) × p_i^γ / Σ_j p_j^γ + ε / N
```

初始 ε = 0.1，γ = 2，N 仅包括启用且本轮未出现的候选。ε 不自动从一次吃/不吃反馈中更新。记录实际选择概率，便于后续审计与策略评估。

## 收敛的三个层次

1. 固定数据集上的优化收敛：A、B 的凸目标容易分析；C 一般只能讨论局部行为。
2. 在线参数收敛：除合适步长外，还需要稳定的响应规律、持续采样、可识别性和相应随机近似条件。自适应推荐与吃后重置会改变采样分布，不能仅凭凸性就宣称整个在线闭环必然收敛。
3. 学到真实个人周期：还取决于模型是否正确、记录是否完整和反馈是否足够。参数稳定与正则下的唯一解都不是准确性的证明。

可以使用 η_n = η0 / (1+n/n0)^α，其中 1/2 < α ≤ 1，使 Ση_n = ∞ 且 Ση_n² < ∞。n 应按每个选项的有效反馈计数。学习率存在正下限时，更适合追踪变化，不再具有上述严格点收敛的保证。

## 推荐的演进路径

按用户选择实施 B，以 (a,b) 存储并学习两个参数，用正则向初始值收缩。模型 A 作为固定斜率对照；是否更换训练策略依据时间覆盖与留出预测误差，不只看一个固定反馈次数。模型接口与训练配置保留版本。

如果真实反馈明显呈现低长期接受率，再比较 C。模型切换时用原始有效反馈重训，不沿用此前单参数合成实验的结论。

未来可加入场景向量：p = σ(a_i + b_i x + βᵀz)，例如午餐/晚餐、工作日/周末。z 不再含与 a_i 重复的截距；β 可以在食物间共享以减少数据需求。在 β 与 (a_i,b_i) 线性进入 logit、使用凸约束与正则的情况下，仍保留固定数据集上的凸性。
